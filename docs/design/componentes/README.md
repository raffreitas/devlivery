# Componentes do Devlivery

Especificações dos componentes de domínio que o shadcn não tem. Cada arquivo diz o que o componente mostra, o que recebe e as regras de uso. Implemente-os em `apps/web/src/shared/components/` com Tailwind e os tokens do tema; a aparência de referência está nas telas de [../telas/](../telas/).

| Componente | Usado em |
| --- | --- |
| [StatusBadge](StatusBadge.md) (e `StatusIcon`) | Pedidos, celular, tabelas, dashboard |
| [OrderCard](OrderCard.md) | Quadro de pedidos, celular |
| [OrderRow](OrderRow.md) | Lista de pedidos |
| [StatTile](StatTile.md) | Caixa, dashboard, histórico |
